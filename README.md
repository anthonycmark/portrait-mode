# Pocket Stakes

A portrait-first, installable poker roguelike designed for phones. Select up to five cards, build poker hands, beat escalating round targets, and buy scoring charms between rounds.

## Play

The game is published with GitHub Pages. On iPhone, open the game in Safari, tap **Share**, then **Add to Home Screen**.

## Local preview

Serve the `dist` folder with any static web server. The game has no build step or external dependencies.

This is an original game implementation and does not contain code, art, music, names, or other assets from Balatro.
